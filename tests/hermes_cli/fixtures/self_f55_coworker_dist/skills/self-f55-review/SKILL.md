# self-f55-review

Example capability skill for the SELF-F55 coworker-type distribution. Distribution
skills live under `skills/<cap>/SKILL.md` and are copied into the installed profile;
install bootstraps an empty `skills/` directory, so this real `SKILL.md` payload is
what proves the distribution's skills actually travelled with it.
